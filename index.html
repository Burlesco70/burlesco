Burlesco — Repository Kodi

Repository sorgente per installare e aggiornare gli add-on Kodi di Burlesco.

URL da aggiungere in Kodi

https://Burlesco70.github.io/burlesco

Come installare

  1. Aggiungi la sorgente sopra in Kodi (Sistema → Impostazioni → Add-on → Origini → Aggiungi sorgente file).
  2. Installa il repository: repository.burlesco-1.0.0.zip.
  3. Da "Cerca" installa gli add-on disponibili (es. Castellano - TV spagnola).

File del repository

  • addons.xml (indice)
