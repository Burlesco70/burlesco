Burlesco — Repository Kodi

Repository sorgente Kodi per installare e aggiornare automaticamente gli add-on di Burlesco.

Add-on disponibile

Castellano - TV spagnola plugin.video.castellano
Per imparare lo spagnolo guardando la TV spagnola. Include:

  • Canali RTVE in diretta (La 1, La 2, Teledeporte, 24h, Clan)
  • Canali TDT per categoria (con filtro dei feed solo-Spagna)
  • Pluto TV Spagna
  • Plex Spagna (per categoria, con token personale opzionale)
  • FAST Spagna (sperimentale)
  • RTVE on-demand con sottotitoli in spagnolo

URL da aggiungere come sorgente in Kodi

https://Burlesco70.github.io/burlesco

Come installare

  1. In Kodi: Sistema → Impostazioni → Add-on → Origini → Aggiungi sorgente file → incolla l'URL sopra → nome "Burlesco".
  2. Installa il repository: repository.burlesco-1.0.0.zip.
  3. Add-on → Installa da repository → Burlesco → Castellano → Installa.

Da qui gli aggiornamenti sono automatici.
